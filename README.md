# Optical Diffraction

A Python package for vector diffraction theory and Monte Carlo scattering analysis of optical beams.

## Features (Planned)
- Richards-Wolf vector diffraction theory for CW and pulsed beams
- Monte Carlo photon transport simulations
- Beam quality analysis and comparison metrics

## Installation

For development:
```bash
git clone <your-repo>
cd optical-diffraction
pip install -e .
```
